# 代理管理与账号设置

代理配置由控制台「代理管理」维护，保存在 `accounts_db` 指定的 SQLite 库中。
`config.json` 不再读取 `proxies`、`proxies_mode`；旧配置项会被忽略，已有代理需要在页面添加并分配给账号。

代理列表展示序号、类型、HOST、PORT、USER_NAME、PASSWORD、延迟(ms)、出口IP、出口地区、创建时间、账号及操作，不展示测试时间列。
账号列使用 tag 显示绑定该代理的账号数量，包含已禁用或暂不可用但仍绑定该代理的账号，随列表查询实时统计。
创建时间写入 SQLite，修改和测试不改变该时间；旧代理自动从生成的 ULID 恢复创建时间，无法恢复的记录显示「—」。
支持 `http`、`https`、`socks5`，端口范围 1–65535，用户名和密码可为空。
列表密码显示掩码，修改弹窗可编辑实际密码。新代理延迟、出口和测试时间为空；修改配置后旧延迟、出口和测试时间清空。

新增代理弹窗提供「测试」按钮，直接测试填写的配置，返回延迟和出口信息，不读取或写入代理记录；测试后仍需点击「保存」才能创建代理。修改表单后清除弹窗的旧测试结果。测试按钮文字保持不变，请求期间禁用操作。

点击「测试」时，用指定代理向上游 `chat_completions` 地址发送无账号凭据的空 POST。
延迟是新建代理连接到收到响应头的耗时，包含代理连接和 TLS 协商，不包含完整推理及出口查询耗时。
成功或预期的参数/认证错误（400、401、405、422）视为地址可达，407、403、5xx 及网络失败视为测试失败。
每次测试完成后更新并持久化最新测试时间，包含失败的测试；未测试或无法恢复历史测试时间的代理显示「—」。测试成功后提示毫秒值并持久化；失败保留上次测量值。测试期间代理被修改或删除，旧测试结果不会写回。
上游地址可达后，通过同一个代理客户端调用 `http://ip-api.com/json?lang=zh-CN`，获取完整默认 JSON 结果，包括出口 IP、国家、地区、城市、坐标、时区和运营商等。免费接口只支持 HTTP，参见 [IP-API 文档](https://ip-api.com/docs/api:json)。出口查询不回退直连，超时上限为配置的请求超时与 10 秒中的较小值。
列表测试将本次出口信息保存到 SQLite，刷新或重新进入页面仍可查看。出口接口失败或限流时单独提示原因，保存成功的上游延迟并清空本次无法获取的出口；上游连通性失败则保留上次延迟和出口，只更新测试时间。
出口IP可点击，详情弹窗展示 IP-API 所有返回字段及原始 JSON。完整 JSON 随列表测试保存为快照；新增弹窗的测试结果也可直接查看详情，仍不写库。已有记录尚无完整 JSON 时，通过该代理查询已保存的出口 IP 并补存详情，不改变延迟和测试时间；配置或出口信息在查询期间变化时，不覆盖新结果。
新增弹窗及列表测试复用请求日志中间件的请求 ID 和控制台完成日志，开始、响应状态、出口信息及结果保存使用 `info`，失败使用 `warn`，默认日志级别即可看到。代理测试不写入推理请求日志表。

账号增加 `use_status`（`enable` / `disable`）与 `proxy`（`direct` / 代理 ID）。
新增导入默认禁用、直连；重复导入保留已有启用状态与代理选择。
旧库账号迁移为启用、直连，保留已有调度行为。启用状态与账号额度、冷却、令牌可用性独立。
卡片提供启用/禁用和「代理」按钮，代理弹窗可选直连或从代理列表选择一个代理。
卡片的创建时间、额度同步时间和代理配置按三行排列。账号视图增加 `proxy_config` 展示字段，直连为 `direct`，代理为 `http://host:port`、`https://host:port` 或 `socks5://host:port`，不包含用户名和密码；IPv6 HOST 使用方括号。账号的 `proxy` 字段继续保存 `direct` 或代理 ID。
禁用账号不参与聊天和模型查询的选号，也不进行定时额度刷新；手动刷新和恢复不自动启用账号。

所有账号请求均在选号后使用该账号的 `proxy` 设置：直连或指定的单个代理。
聊天、附件注册及上传、模型查询（含定时刷新和 readiness 探测）、额度刷新、令牌续期、输入图片 URL 下载和生成图片下载均遵循该设置。
共享客户端只提供连接池和代理配置存储，未选号时不能发送账号请求；不存在全局代理模式或多个代理之间的轮换。
聊天响应携带已选账号的图片下载客户端，断流重试换号后随新响应更新，不会因为缺少客户端而隐式直连。
代理列表的连通性测试独立使用待测试代理，不选号，也不回退直连。
设置代理弹窗增加「代理失败回退直连」，默认不勾选，按账号保存为 `proxy_fallback_direct`。
勾选后先使用指定代理，连接失败、响应头超时或代理认证失败（407）时回退直连。
未勾选时代理失败直接报错。上游账号认证、限额等 HTTP 业务错误继续走原有处理流程。
图片下载仅在账号允许回退时可尝试直连；下载或格式校验失败继续按图片省略逻辑处理。
令牌续期涉及一次性令牌轮换，仅代理连接建立失败时允许直连重试，避免重复提交已送出的续期请求。
切换为直连后清除回退选项。直连显式绕过系统代理环境变量。
被账号引用的代理不能删除，需要先修改相关账号的代理设置。

以下接口均使用现有管理入口鉴权和响应格式，方法为 POST：

| 路径 | 请求内容 |
| --- | --- |
| `/v1/proxies/list` | `{}` |
| `/v1/proxies/create` | `type`、`host`、`port`、`user_name`、`password` |
| `/v1/proxies/update` | 同新增，并增加 `id` |
| `/v1/proxies/delete` | `id` |
| `/v1/proxies/test` | `id`，成功返回 `latency_ms`、`tested_at`（Unix 秒）、`exit_ip`、`exit_location`、`exit_details`（JSON 对象）、`exit_error`；保存结果 |
| `/v1/proxies/test-config` | 同新增配置，返回 `latency_ms`、`exit_ip`、`exit_location`、`exit_details`（JSON 对象）、`exit_error`；仅测试，不写库 |
| `/v1/proxies/exit-details` | `id`，返回保存的完整 IP-API JSON，旧记录缺少详情时查询该 IP 并补存 |
| `/v1/accounts/settings` | `email` 加 `use_status` 或 `proxy`；修改代理时可同时传 `proxy_fallback_direct`（布尔值） |

升级后需要重新编译并重启服务，启动时自动完成建表、账号列迁移、代理测试时间、出口及详情列迁移和创建时间回填。
